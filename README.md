# TypeScript Advanced Assignment

In this project, 7 problems have been solved using TypeScript as per the assignment requirements. And a technical blog has been created.

## 📁 File Structure

- **solutions.ts**: Contains comprehensive solutions to 7 complex coding problems.
- **blog-1.md**: A technical deep dive into "`any` vs `unknown`" and the importance of Type Narrowing.
- **blog-2.md**: A detailed post on "`Generics`" and how they enable building reusable, type-safe components.
- **README.md**: Project documentation and setup guide.

## 🚀 How to Run

To execute the solutions on your local machine, follow these steps:

1. Ensure you have **Node.js** and **TypeScript** installed.
2. Install necessary dependencies:
   ```bash
   npm install
   ```
3. Run the solutions file directly using `ts-node`:

```bash
   npm ts-node solutions.ts
```
